Section 01

Tokens

The atomic values. Every color, type size, radius, and shadow used across the blog index and post template. Anchored on a two-tier dark system: --black for hero/nav authority, --charcoal-deep for secondary dark surfaces.

Color --color-*

TokenHexUsage
--black #000000 Primary dark. Site header, hero, top-of-page authority surfaces, End CTA band. Not for footer, inline CTAs, or body text.
--charcoal-deep #0F172A Secondary dark. Footer, inline article CTA blocks, Culture pillar badge. Also doubles as --ink for primary body headings.
--charcoal-mid #1E293B Borders on dark surfaces, subtle divider between dark sections, newsletter input background.
--charcoal-line #334155 Borders on darker components (pill outlines on dark, input borders).
--yellow #FFC200 Primary CTA / accent. Buttons, accent words in headlines, active nav states, left-border stripes on inline CTAs, underlines on editorial links. The only accent color that appears on every page.
--yellow-hover #E6AE00 Hover state for primary yellow buttons only.
--green #0A8754 Secondary accent. Positive signals (checklist checkmarks), Seller Education + Market Data pillar badges, copied-confirmation state.
pillar--homeowner #B45309 Homeowner Help pillar badge only. Not a general-purpose token.
--ink #0F172A Primary body text and headings on light surfaces. Same value as --charcoal-deep, separate name by intent.
--ink-2 #334155 Body copy paragraphs, card excerpts, supporting text.
--ink-3 #64748B Meta (dates, read time), tertiary labels, placeholder text.
--surface #FFFFFF Default page background, card surfaces.
--surface-alt #F8FAFC Post grid section background, pull-quote background, tag/sort chip backgrounds, Related Posts band.
--surface-border #E2E8F0 All light-surface borders (cards, inputs, dividers).

Section 03

Editorial rules

Voice and naming constraints baked into the system. If you're writing or reviewing post copy, these override anything else.

Brand name required

Restore STL — two words, space between. Never RestoreSTL or RESTORESTL in customer-facing copy. The only exception is the wordmark treatment, which visually joins them via the yellow "STL" color shift.

Byline required

Every post is bylined By the Restore STL Team. Contributors go on a smaller credit line beneath ("Research and editing: {name}"). Never byline Kevin directly on blog posts.

Kevin's experience required

When referencing Kevin's background, say 20 years in St. Louis real estate. Do not inflate to 25+ years. Accuracy compounds.

Tone required

Open-book, plainspoken. Write like you're explaining something to a family member across the kitchen table. Specifics over superlatives. Numbers over adjectives. Admit what's hard.

No AI language forbidden

Never use AI-powered, smart algorithm, or similar tech-marketing phrasing. The brand is built on human judgment and local knowledge — don't undercut that.

No Keystone Collective forbidden

Do not reference Keystone Collective anywhere in customer-facing copy. Cross-site links to sister brands (PHSTL, SFSTL) use their own names directly — see Design Gap D.

Wordmark brand

In running text, write "Restore STL". In the wordmark/logo treatment, it becomes RESTORE STL — Montserrat 800, 0.04em tracking, yellow on the STL. This is the only place the name typesets as one visual unit.

Accent word treatment brand

Headlines can use one yellow accent word (e.g. "Stories from the Gateway City"). One per headline max. Never on body copy, never on meta text.

Section 04

Known gaps & future work

What this design system does not yet define. When a future session needs one of these, it extends the system — it doesn't overwrite it.

Design Gap A · queued

Neighborhood hub page template

A landing template for individual neighborhoods (Lafayette Square, Tower Grove South, The Hill, Soulard, etc.). Will include a local hero, recent comps band, related posts filtered by neighborhood tag, and a neighborhood-specific CTA. Separate session.

Design Gap B · queued

Pillar-specific post variants

Four variants of the Blog Post Template, one per editorial pillar where structure differs meaningfully: Seller Education (FAQ module), Market Data (data viz + table patterns), Culture & Local Life (photo-led hero), Homeowner Help (step-by-step layout). Each inherits 100% from base; adds section components only.

Design Gap C · blocked

PartnerSlot component

Contextual partner feature block. Slot defined in base template; component styling + content model pending. See Components § PartnerSlot. Blocked on partner agreements finalizing.

Design Gap D · blocked

Cross-site link patterns (PHSTL, SFSTL)

Visual treatment for links from Restore STL content to sister-site properties. Needs to signal "this is a related brand, not a third-party". Blocked on sister-brand visual audit.

Design Gap E · pending

Real photography guidelines

Tone, framing, and color-grading rules for original Restore STL photography (Kevin, neighborhoods, houses, closings). Pending delivery of the first shoot asset library. Until then, Unsplash placeholders acceptable in mockups only.

Design Gap F · pending

Comments / social proof pattern

Not scoped in v1. If we add reader responses, testimonials, or Google review surfacing, it lands here. For now, posts end at the End CTA — no comment thread.
